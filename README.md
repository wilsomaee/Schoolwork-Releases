# Schoolwork

Schoolwork is a Windows app for managing classes, assignments, tests, GPA, reminders, and study planning in one place.

### Features

- Assignments, tests, and coursework
- Automatic planning around your schedule
- Interactive Timeline with drag-and-drop work blocks
- A/B day support
- Canvas due-date import
- GPA and grade-target tracking
- Reminders and tray support
- Optional Study Help

### Download

Go to **Releases** and download:

`Schoolwork-Setup-2026.08.30.exe`

Windows 10/11 64-bit. No separate .NET install required.

Schoolwork is currently unsigned, so Windows may show an **Unknown Publisher / SmartScreen** warning.
