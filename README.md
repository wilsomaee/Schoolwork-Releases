# Schoolwork

> **Note for Windows users**
>
> Schoolwork isn't signed with a paid commercial certificate yet, so Windows
> SmartScreen may flag the installer. It isn't malware — Windows just doesn't
> recognise the publisher yet.
>
> To run it: click **More info** on the blue popup, then **Run anyway**.
>
> Every release lists a SHA-256 you can check your download against.

Schoolwork is a Windows app for managing classes, assignments, tests, GPA, reminders, and study planning in one place.

### Features

- Assignments, tests, and coursework
- Automatic planning around your schedule
- Interactive Timeline with drag-and-drop work blocks
- A/B day support
- Canvas due-date import
- GPA and grade-target tracking
- Reminders and tray support
- Optional Study Help

### Download

Go to **Releases** and download:

`Schoolwork-Setup-2026.09.01.exe`

### System Requirements

**Windows**

- Windows 11, 64-bit recommended
- Windows 10 only where Microsoft still supports the underlying .NET 10 runtime
- x64 processor
- No separate .NET installation required

**macOS** — not released yet; Apple Silicon build in testing

- macOS 14 Sonoma or newer
- Apple Silicon (M1 or newer)
- No separate .NET installation required
